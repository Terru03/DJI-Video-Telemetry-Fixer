# DJI Mini 3 Pro Telemetry & Metadata Fixer

Recover lost GPS, Date, and Camera settings for DJI Mini 3 Pro videos after editing interactively. This script injects metadata back into your exported videos (MP4/MOV) by reading the original `.SRT` subtitle files generated by the drone.

It writes GPS and capture dates in metadata fields used by **Google Photos**. Read-back verification confirms the required file tags; Google Photos display behavior is not tested by this script.

## Features

-   **GPS Injection**: Restores Latitude, Longitude, and Altitude.
-   **Google Photos Metadata**: Uses ISO 6709 formatting and `Keys` atoms for location.
-   **Telemetry Subtitles**: Embeds the original `.SRT` flight data (ISO, Shutter, Altitude, etc.) as a soft subtitle track you can toggle on/off.
-   **Camera Settings**: Injects ISO, Shutter Speed, and F-Number into metadata tags.
-   **Verified Processing**: Checks required GPS/date tags and, when requested, the telemetry subtitle before reporting success. Cached filenames and camera model tags are hints; current export verification is required before skipping.
-   **Space Saver**: Optional `--delete-source` flag to recycle original source video only after new processing and verification. Already-processed skips always preserve source.

## Prerequisites

1.  **Python 3.6+**: [Download Python](https://www.python.org/downloads/)
2.  **ExifTool**: Required for writing metadata.
    *   [Download ExifTool](https://exiftool.org/)
    *   Make sure `exiftool.exe` is in your system PATH or in the same folder as the script.
3.  **FFmpeg and ffprobe**: Required for embedding and verifying subtitle tracks, unless `--no-subtitle` is used.
    *   [Download FFmpeg](https://ffmpeg.org/download.html)
    *   Make sure `ffmpeg.exe` and `ffprobe.exe` are in your system PATH.

## Installation

1.  Clone or download this repository.
2.  Ensure you have the prerequisites installed.
3.  Place your exported/edited videos in a folder (e.g., `Exported`).
4.  Ensure you have your original source folder (e.g., `Source`) containing the original `.MP4` and `.SRT` files.

## Usage

1.  Edit `run_injection_template.bat` (Right-click -> Edit).
2.  Set `SOURCE_DIR` to your original DJI folder.
3.  Set `EXPORT_DIR` to your edited videos folder.
4.  Save and double-click the batch file to run!

### Advanced Command Line Usage

```bash
python inject_dji_metadata.py "C:\Path\To\Source" "C:\Path\To\Exports" [options]
```

**Options:**
-   `--force`: Re-process files even if they already appear to have metadata.
-   `--delete-source`: **WARNING**: Moves original source MP4/MOV to the Recycle Bin only after new processing and required metadata/subtitle read-back verification. SRT files and already-processed sources are preserved. Check your exports before enabling this option.
-   `--no-subtitle`: Process metadata only; FFmpeg/ffprobe are not required. GPS/date verification still applies.
-   `--threads N`: Deprecated compatibility option (Default: 1). Accepted for existing batch files but ignored: processing is always serial.
-   `--delay N`: Seconds between files (Default: 5; use 0 to disable).

Source and export must be separate files; case aliases and detectable symlink/hardlink aliases are rejected before editing. Ambiguous sibling MP4/MOV sources and duplicate SRT filenames in the source tree are rejected. Missing tools, incomplete/invalid GPS or capture date, write failures, and read-back mismatches produce errors and preserve source video. Failures can leave a partially processed export; review it before retrying. The CLI exits nonzero for missing directories/tools or failed matched videos.

## How It Works

1.  **Scans** your Source directory for `.SRT` files.
2.  **Matches** them to videos in your Export directory based on filename (e.g., `DJI_0001.SRT` matches `DJI_0001_Edited.mp4`).
3.  **Parses and validates** the SRT GPS and capture timestamp before editing.
4.  **Embeds** the SRT as a subtitle track using FFmpeg, unless `--no-subtitle` is selected.
5.  **Injects** the metadata using ExifTool into `Keys`, `QuickTime`, and `XMP` tags for maximum compatibility.
6.  **Verifies** signed `Keys:GPSCoordinates`, local `Keys:CreationDate`, and `QuickTime:CreateDate` using ExifTool JSON, plus a `mov_text` telemetry track using ffprobe when subtitles are requested. Coordinates tolerate five-decimal encoding and altitude three decimals. The SRT provides no timezone; verification compares local date/time to the second.
7.  **Tracks** only verified processed results and optionally recycles source after new successful processing.

The `.dji_processed.json` cache remains a filename hint, not proof of export contents. Read-back verifies the selected GPS/date fields and presence of a telemetry subtitle; it does not prove complete media integrity, every optional camera tag, or cloud-service behavior.
